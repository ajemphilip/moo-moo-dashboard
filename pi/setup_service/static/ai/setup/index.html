Set up a local machine

A computer at home that does Moo's listening, stories and voice.

1 · A computer: Windows, Mac or Linux

The best quality. On that computer, download Moo Local and open the file. It installs Moo Local into your home folder (about 2 GB of programs, so allow some time) and starts it. It then starts by itself whenever someone logs in, and the computer appears under Devices. No AI model is downloaded yet: choose the story, listening and voice models afterwards under Models on the AI engine screen. A model too big for that computer is refused, with a smaller one to try.

This looks like a phone or tablet. Open this page on the computer that should do the work, or choose its system below.

Download for Windows

Also for Mac · Linux

Open Install Moo Local.cmd from Downloads. If the browser warns about the file, choose Keep. The file is not signed, so Windows SmartScreen asks once: choose More info → Run anyway. Near the end Windows asks for a Yes, so the Moo can reach this computer through the firewall.

Or with a Terminal line (Mac or Linux)

Paste this line into Terminal and press Return. It does the same as the download.

curl -fsSL http://moo.local:8000/local-ai/install.sh | bash

2 · Any device, nothing to install

Open the Moo website on that computer, tablet or phone, go to AI engine and tap This device. Its browser then does the work, and the device appears under Local machines for as long as the page stays open.

3 · A machine that is not found by itself

If a computer runs Moo Local but does not show up, type its address, for example 192.168.1.20.
