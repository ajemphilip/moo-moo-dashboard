Set up a local machine

A computer at home that does Moo's listening, stories and voice.

1 · A Mac with Apple silicon

The best quality. Open Terminal on that Mac, paste this line and press Return. It installs Moo Local (about 5 GB), downloads a story model and the voices, and starts it. The Mac then appears under Local machines.

curl -fsSL http://moo.local:8000/local-ai/install.sh | bash

After the Mac restarts, Moo Local has to be started again. The installer prints the command for that.

2 · Any other computer, tablet or phone

Nothing to install. Open the Moo website on that device, go to AI engine and tap This device. Its browser then does the work, and the device appears under Local machines for as long as the page stays open.

3 · A machine that is not found by itself

If a computer runs Moo Local but does not show up, type its address, for example 192.168.1.20.
